一周使用指南 · 金桑的皮卡丘

手机是主设备，电脑用来生成周报。 这份是照着做就行的操作手册。

第一天 · 把工作台装到手机上（约 5 分钟）

① 传文件

电脑上打开微信 → 文件传输助手 → 把这两个文件拖进去发送：

D:\Deepseek Work\金桑的皮卡丘\index.html
D:\Deepseek Work\金桑的皮卡丘\icon.png

② 在手机上用「系统浏览器」打开（关键）

iPhone（用 Safari）

  1. 手机上打开微信文件传输助手，点 index.html
  2. 右上角 「···」→「用其他应用打开」→ 选 Safari

安卓（用 Chrome 或系统浏览器）

  1. 点 index.html → 右上角 「···」
  2. 选 「用浏览器打开」 → 选 Chrome
⚠️ 绝对不要在微信里直接用。
微信内置浏览器会清缓存，你记的东西关掉就没了。

怎么确认跳出来了：地址栏能看到 file:///... 开头、有浏览器自己的菜单栏。
如果顶上还是微信的返回按钮、没有地址栏 → 还在微信里，退出去重来。

③ 存成书签（以后一秒打开）

Safari：底部中间 分享 按钮 → 「添加书签」 → 存到「个人收藏」

Chrome：右上角 ⋮ → 星星图标 → 保存

以后从书签进。 这是没有域名时最接近"App 图标"的做法。

④ ⚠️ 必须验一次：数据真的存住了吗

这一步别跳过。

  1. 打开「随手记」，写一条，比如 测试手机存储
  2. 把浏览器从后台完全划掉（不是只按 Home 键）
  3. 从书签重新打开
  4. 看那条还在不在
  • 在 → 成了，可以开始天天用
  • 不在 → 立刻告诉我，得换浏览器或换方案

日常怎么记（这是它最值钱的地方）

场景一：微信/企微/邮件里看到要跟的事

别手打，直接复制粘贴。

  1. 在微信里长按那条消息 → 复制
  2. 打开工作台 → 「智能整理」
  3. 粘到框里 → 点「识别要跟的事」
  4. 它会把要跟的事挑出来，你扫一眼：
  • 判断错了 → 点方框改成「待办/备忘」
  • 缺标签 → 点下面的标签加上
  • 缺截止日 → 点「定截止日」
  1. 点「导入选中的」

一句话总结：它干掉 80% 的体力活，剩下 20% 你扫一眼补。

它不懂语气 —— 「老板语气不太对，这事估计得赶紧办」这种认不出来，得你自己补。

场景二：临时想起一件事

走「随手记」：一个框、一句话、点「记下」。20 秒完事。

如果是要跟的事，「这是个待办」那个勾保持勾选，再点一下上面的标签。

场景三：开会/路上记完，回到电脑上

不用管，每周合并一次就行（见下）。

每天花 2 分钟

早上：「今日」页看一眼

打开就是「今天要跟的事」+「今天新进的事」。

点「📋 复制今日提醒」 → 粘到自己的微信文件传输助手。

相当于自己给自己发一条提醒。（网页做不到主动推送，这是最接近的办法。）

晚上：「复盘」页写三句

  1. 今天最重要的三件事
  2. 卡在哪了 —— 谁在等我的东西？什么没推动？
  3. 明天第一件事做什么

第 3 条会自动变成明天的待办，不用你再记一遍。

今天的流水就在下面那张卡里，照着写，两分钟能完事。

勾错了怎么办（三条后悔路）

什么时候后悔怎么救
刚勾完屏幕底部弹提示 → 点 「撤销」（停 6 秒）
过一会儿才想起来「待办」页 →「显示已完成的」→ 点那个勾就收回
在今日页最下面「今天完成的」→ 点勾收回

每周花 5 分钟（两条纪律）

纪律一：备份（最重要，别偷懒）

  1. 「设置 → 数据备份 → 导出备份」
  2. 会下载 皮卡丘备份-xxxx-xx-xx.json
  3. 转发到微信文件传输助手 / 存百度云 / 存 iCloud

为什么必须做：iOS 对本地文件打开的数据有清理机制，7 天不打开可能被清掉。

导出一次，就等于把命保住了。

工作台会提醒你（超 7 天没备份，顶上冒黄条），但别等它提醒。

纪律二：和电脑合并一次（要电脑上也有记录才做）

它只合并、不覆盖，来回导不会丢数据。

先 手机 → 电脑：

  1. 手机「导出备份」→ 发微信文件传输助手
  2. 电脑下载那个 json → 「恢复备份」→ 选中它

再 电脑 → 手机：

  1. 电脑「导出备份」→ 发微信文件传输助手
  2. 手机下载 → 「恢复备份」→ 选中它

⚠️ 两个方向都要做，只做一个方向的话只有一边的数据会补过去。

周报怎么出（周五下午，3 分钟）

  1. 电脑上打开工作台 → 「周报」页
  2. 它已经按项目分好组了：本周完成 / 本周新增 / 没做完的顺延
  3. 点「📋 复制周报」
  4. 粘到群里或周报文档里，不用再排版

往前翻历史周报：点「← 上一周」。月报在「月报」页，同样操作。

一周后回来告诉我这几件事

我根据这些判断下一步帮你做什么（比如要不要做小程序）：

留意什么为什么重要
哪些功能天天用、哪些一直没碰做小程序时只做常用的，砍掉不用的
哪个动作觉得"麻烦"那是最该优化的地方
粘聊天记录识别得准不准不准我就调规则
有没有"想记但懒得打开"的时候说明需要推送提醒，或者需要更省事的入口

随手记在手机备忘录里就行，不用特意整理。

出问题时的快查

现象怎么办
记的东西刷新后没了是不是在微信里打开的？必须跳到系统浏览器
找不到「添加到主屏幕」正常 —— 没有域名时加不了桌面。想加要买域名（几十块）
想换配色「设置 → 配色」，三套随便换，不影响数据
想换头像「设置 → 头像 → 上传新头像」，只存你手机里，别人看不到
手机上打开是空的正常 —— 数据不跟链接走，跟设备走。要两边都有就用上面的合并流程
想加个新功能直接跟我说「给我的工作台加个喝水提醒」

想升级的话（都不急，用顺了再说）

花多少换来什么
买个域名几十块/年（选不含中国大陆节点，不用备案）手机加到桌面像 App + 手机电脑自动同步（不用再手动导）
做微信小程序要重写界面 + 审核 1-7 天微信里点开 + 主动推送提醒 + 数据不会被系统清

建议：先用一周。 如果你发现真的每天都离不开它，那时候再花这个钱，而且你会更清楚哪些功能常用、哪些可以砍。

别为了"想要一个 App"而做一个 App。
