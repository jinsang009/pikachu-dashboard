第 4.5 步 · 买域名（想要手机桌面 / 自动同步时做）

只有这一步是花钱的，几十块一年。 而且不用备案，看下面。

为什么必须买

  • 免费版的默认域名 xxx.edgeone.cool 绑在"预览"环境上，必须带 eo_token 访问
  • 那个 token 有有效期，会过期 → 加到桌面后过几天打开就是 401
  • 「项目设置 → 环境管理」里「生产」环境的域名栏是空的，绑不上免费域名

想要永久网址（能加桌面、能开同步），只有「添加自定义域名」这一条路。

买什么、多少钱

后缀大致价格建议
.xyz / .top首年 1-10 元，续费 20-40/年最便宜
.cn首年约 20-30 元，续费 30-40/年国内常用
.com首年约 50-80 元，续费 70-90/年最通用

去哪买都行（腾讯云 / 阿里云 / 其他）。买完要做实名认证（身份证，1-2 小时出结果）。

⚠️ 关键：选「不含中国大陆」的节点，就不用备案

腾讯云官方规定（原文）：

加速区域为「全球可用区」或「中国大陆可用区」的域名必须完成 ICP 备案。
未备案域名仅可选择「全球可用区（不含中国大陆）」。

翻成大白话：

你的选择要不要备案代价
用不含中国大陆的节点❌ 不用备案国内访问稍慢一点（但完全能用）
用含中国大陆的节点✅ 要备案1-2 周，还要身份证、可能接核验电话

走第一条。 这是给自己用的工作台，慢几十毫秒无所谓。

还有一个坑要先确认

⚠️ 我们那个项目创建时选的加速区域是「全球可用区（含中国大陆）」。

这意味着现在直接绑域名可能绑不上，得先把加速区域改成"不含中国大陆"。

能不能改我还不确定（可能要重建项目）。不过就算重建也不麻烦：

  • 代码在 GitHub 上，重新导入一次就行
  • 你的数据一条都不会丢 —— 数据在你浏览器里，跟部署完全无关

买完之后的步骤

  1. EdgeOne 项目 →「域名管理」→「添加自定义域名」→ 填刚买的域名
  2. 加速区域选「全球可用区（不含中国大陆）」
  3. 去域名注册商加一条 CNAME 解析，值从 EdgeOne 页面上复制
  4. 等生效（几分钟到几小时），平台会自动配 HTTPS 证书
  5. 拿到域名后：手机 Safari 打开 →「添加到主屏幕」
  6. 然后才能开双端同步（见第 7 步）

到时候截图给我，我一步步带你。

第 1 步 · 在 GitHub 建一个空仓库 ✅ 已完成

  1. 浏览器打开 https://github.com/new
  2. Repository name 填：pikachu-dashboard
  3. Description（可留空）：金桑的皮卡丘 · 个人工作台
  4. 选 Private（私有）或 Public 都行 —— 注意：都不要勾下面那三个初始化选项

（Add a README / .gitignore / license 一个都别勾，勾了会跟我们本地的东西打架）

  1. 点最下面绿色的 Create repository
  2. 建好之后页面会显示一串地址，类似：

https://github.com/你的用户名/pikachu-dashboard.git

把这行地址复制下来给我

第 2 步 · 建一个上传用的令牌（token）

GitHub 从 2021 年起就不能用账号密码推代码了，必须用令牌。

  1. 打开 https://github.com/settings/tokens?type=beta
  2. 点 Generate new token
  3. Token name 填：皮卡丘工作台上传
  4. Expiration（有效期）：选 90 天就行（过期了再建一个，不麻烦）
  5. Repository access：选 Only select repositories，然后选中第 1 步建的那个 pikachu-dashboard
  6. Permissions → 展开 Repository permissions → 找到 Contents → 改成 Read and write
  7. 拉到底点 Generate token
  8. 页面上会出现一串 github_pat_... 开头的字符，只有这一次能看见，现在就复制存好
⚠️ 这串令牌等于你家钥匙，不要发给我、不要发到任何群里、不要截图。
我给你的命令里只需要你在提示符下自己粘贴，我看不到就不会泄漏。
万一不小心发出来了，回第 1 步那个页面把它删掉，重新建一个就行。

第 3 步 · 把代码推上去

代码我这边已经提交好了（7 个文件，预览资料已经排除干净）。你只需要跑三条命令。

打开 PowerShell，逐条粘贴执行（第二条把 你的用户名 换成你的 GitHub 用户名）：

cd "D:\Deepseek Work\金桑的皮卡丘"

git remote add origin https://github.com/你的用户名/pikachu-dashboard.git

git push -u origin main

第三条命令跑起来后，会弹出登录框：

  • 用户名：填你的 GitHub 用户名
  • 密码：粘贴第 2 步那串令牌（不是你的 GitHub 登录密码）
如果弹的是浏览器授权窗口，点授权就行，不用填令牌。
如果提示 remote origin already exists，说明第二条之前跑过一次，直接跑第三条即可。

成功后你应该看到类似 main -> main 的输出。把结果截图给我或原文贴给我。

  1. 浏览器打开 https://cloud.tencent.com
  2. 右上角注册，用微信扫码最省事

第 5 步 · 在 EdgeOne Pages 建项目

  1. 搜「EdgeOne Pages」进控制台（或直接开 https://pages.edgeone.ai）
  2. 新建项目 → 这一步要选「从 Git 仓库导入」，不要选直接上传/拖拽

（原因见本文档开头）

  1. 授权连接 GitHub，选中第 1 步那个 pikachu-dashboard 仓库
  2. 构建配置一般不用改，平台会自动识别并安装依赖
  • 如果它要求填「输出目录」，填 .（或者留空）
  • 不要自己去设 npm run build 之类的命令，这个工程不需要构建
  1. 点部署，等 1-2 分钟
成功后你会拿到一个 xxxx.edgeone.app 的链接。这个链接不需要备案，
只有绑自己的域名才要备案，所以别去折腾域名。
⚠️ 腾讯云控制台会改版，按钮名字和位置随时变。
找不到入口就截图发我，我按你屏幕上的实际选项指路——比你自己在控制台里瞎点快得多。

第 6 步 · 加到手机桌面

⚠️ 最关键的坑：微信里打开这个链接是加不了桌面的，微信内置浏览器没有这个功能。

必须先在系统浏览器里打开。

iPhone（用 Safari）

  1. 把链接发到微信文件传输助手 → 手机上点开 → 右上角「···」→「用其他应用打开」→ 选 Safari
  2. 点底部中间的分享按钮（方框 + 向上箭头）
  3. 往下滑，找到「添加到主屏幕」
  4. 名字会自动是「皮卡丘」，点「添加」
  5. 回桌面，⚡ 图标就在那了 —— 点开是全屏的，看不出是网页

安卓（用 Chrome 或其他浏览器）

  1. 同样先跳到系统浏览器打开
  2. 右上角菜单「⋮」
  3. 找「添加到主屏幕」或「安装应用」
  4. 确认

第 7 步 · 开双端同步（最后一步，先备份）

开之前必须先导出一份备份 —— 我会带你做。

  1. 在手机或电脑上打开工作台 → 「设置」→「数据备份」→ 点「导出备份」
  2. 把导出的 皮卡丘备份-xxxx-xx-xx.json 转发到微信文件传输助手存一份
  3. 然后到「设置」→「双端同步」：
  • 用户名：起个好记的，比如 jinsang（3-32 个字符，小写字母数字）

—— 这个只用来定位你的数据，永远不要改，改了就读不到原来的数据了

  • 密码：至少 8 位。忘了就进不去了，没有找回功能
  1. 点「开启同步」
  2. 到另一台设备打开同一个链接，填同样的用户名和密码，数据就对齐了
